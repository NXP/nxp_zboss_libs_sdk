# NXP Zboss SDK for Zephyr

The NXP Zboss SDK for Zephyr provides pre-built Zigbee libraries to develop applications based on NXP SoC.

## Pre-requirements

See the Zephyr documentation's [Getting Started Guide](https://docs.zephyrproject.org/latest/develop/getting_started/index.html) to start developping on Zephyr.
