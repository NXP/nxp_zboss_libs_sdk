Test Script - SDK Samples
===========================
 Objective:
   Test and test scripts under SDK Samples context, performs high-level/functionality checks.

 Devices:
   1. ZC - dualpan_zc
   2. ZR - dualpan_zr
   3. ZED - dualpan_zed

   Multi-Client functionality is possible, refer to readme-example-dualpan_nxp.txt.

 Initial conditions:
   1. All devices are factory new and powered off until used.

 Test procedure:
   Item 1. Start ZC app with ZB channel argument --ch 11, post OT Configured to CH25[via ot-ctl].
   Item 2. Start ZR or ZED app with ZB channel argument --ch 11, post OT Configured to CH25[via ot-ctl].
   Item 3. Start ZC, ZR & ZED app with ZB channel argument --ch 25, in DualPan mode but OT PAN is not configured yet.
   Item 4. Start ZC, ZR & ZED app with ZB channel argument --ch 25, in Standalone mode.

 Expected outcome:
    For 'Test procedure' item 1:
      1.1. ZC -> App senses PAN channel already in use by OT and fails to configure ZB PAN to CH11.
      1.2. ZC -> App Reconfigures PAN channel to CH25
      1.3. ZC -> Broadcast: Beacon Request on CH25
    For 'Test procedure' item 2:
      2.1. ZR/ZED -> App senses PAN channel already in use by OT and fails to configure ZB PAN to CH11. And App Reconfigures PAN channel to CH25.
      2.2. ZC -> Broadcast: Beacon
      2.3. ZR/ZED -> ZC: Association
      2.4. ZR/ZED -> ZC: BDB commissioning
    For 'Test procedure' item 3 & item 4:
      2.1. ZC/ZR/ZED -> App senses PAN channel is NOT in use and it freely configures PAN channel to CH25.
      2.2. ZC -> Broadcast: Beacon on CH25
      2.3. ZR/ZED -> ZC: Association
      2.4. ZR/ZED -> ZC: BDB commissioning
