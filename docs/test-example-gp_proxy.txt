Test Script
============

Devices:
   1. GPS - Any Green Power Combo Coordinator
   2. GPP - gp_proxy (iMx8 + Firecrest board)
   3. GPD - Any Green Power End Device

 Initial conditions:
   1. All devices are factory new and powered off until used.

 Test procedure:
   Item 1. GPS start.
   Item 2. GPP start.
   Item 3. GPD start.

 Expected outcome:
   For 'Test procedure' item 1:
     1.1. Beacon Request
     1.2. GPS -> Broadcast: Permit Join Request
   For 'Test procedure' item 2:
     2.3. GPS: Beacon
     2.4. GPP joins GPS's network
     2.5. GPS sends Security Start Key Update Request and receives a response from GPP (response status is Success)
     2.6. GPS sends Security Start Key Negotiation Request and receives a response from GPP (response status is Success)
     2.7. GPP sends Verify Key and GPS responds with Confirm key.
     2.8. GPS -> GPP: Transport Key with Security header
     2.9. GPP -> Broadcast: Device announcement
     2.10. GPP -> GPS: Security Get Authentification Token Request
     2.11. GPS -> GPP: Security Get Authentification Token Response
     2.12. GPP -> Broadcast: Permit Join Request
     2.13. GPS -> Broadcast: GP Proxy Commissioning Mode (Enter)
     2.14. Broadcast : Channel Request
     2.15. GPP -> GPS:  GP Commissioning Notification (Channel Request)
     2.16. GPS -> Broadcast:  GP Response (Channel Configuration)
      Press Button 1 of the GPS after successful commissioning.
   For 'Test procedure' item 3:
      Press Button 1 of the GPD to do Commissioning of the GP device:
     3.17. GPD -> Broadcast:  Commissioning
     3.18. GPP -> GPS:  GP Commissioning Notification (Commissioning)
     3.19. GPD -> Broadcast:  Commissioning Reply
     3.20. GPS -> Broadcast:  GP Response (Commissioning Reply)
     3.21. GPD -> Broadcast:  Success
     3.22. GPP -> GPS:  GP Commissioning Notification (Success)
     3.23. GPS -> Broadcast:  GP Pairing
     3.24. GPS -> GPP:  GP Proxy Commissioning Mode (Exit)
     3.25. GPD -> Broadcast:  GP Device specific commands (Like: On/Off/Toggle)
     3.26. GPP -> GPS:  GP Commissioning Notification (Like: On/Off/Toggle)
