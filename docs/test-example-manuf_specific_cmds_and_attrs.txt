Test Script - SDK Samples
=============================
 Objective:
   Test and test scripts under SDK Samples context, performs high-level/functionality checks.

 Devices:
   1. ZC - manuf_onoff_output_zc
   2. ZED - manuf_onoff_switch_zed

 Initial conditions:
   1. All devices are factory new and powered off until used.

 Test procedure:
   Item 1. Turn ZC on.
   Item 2. Turn ZED on

 Expected outcome:
    For 'Test procedure' item 1:
      1.1. ZC -> Broadcast: Beacon Request
    For 'Test procedure' item 2:
      2.1. ZC -> Broadcast: Beacon
      2.2. ZED -> ZC: Association
      2.3. ZED -> ZC: BDB commissioning
      2.4. ZED -> ZC: Simple Descriptor Request
      2.5. ZC -> ZED: Simple Descriptor Response
      2.6. ZED -> ZC: Configure Reporting
      2.7. ZC -> ZED: Configure Reporting Response
      2.8. ZED -> ZC: Read Reporting Configuration
      2.9. ZC -> ZED: Read Reporting Configuration Response. ZC -> ZED: Default Response
      2.10. ZED -> ZC: Discover Attributes
      2.11. ZC -> ZED: Discover Attributes Response
      2.12. ZED -> ZC: Discover Commands Received
      2.13. ZC -> ZED: Discover Commands Received Response
      2.14. ZED -> ZC: Discover Commands Generated Request (Wireshark parses it as an unknown command with code 0x13)
      2.15. ZC -> ZED: Discover Commands Generated Response (Wireshark parses it as an unknown command with code 0x14)
      2.16. ZED -> ZC: ZCL On/Off Toggle command
      2.17. ZC -> ZED: Default Response
      2.18. ZED -> ZC: Manufacturer-specific command with id = 0x02 and data 0x01 (1 byte) (Wireshark parses it as unknown command)
      2.19. ZC -> ZED: Default Response
      2.20. ZED -> ZC: Read Attributes
      2.21. ZC -> ZED: Read Attributes Response
      2.22. ZED -> ZC: Write Attributes
      2.23. ZC -> ZED: Write Attributes Response
      2.24. ZED -> ZC: Manufacturer-specific command with id = 0x02 and data 0x00 (1 byte) (Wireshark parses it as an unknown command)
      2.25. ZC -> ZED: Default Response
