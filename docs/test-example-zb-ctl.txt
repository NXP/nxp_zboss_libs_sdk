./imx-dualpan.sh --zb zb_daemon_zczr --ot ot-daemon [--fw <IW612-firmware>]

From another console:

ot-ctl fwversion
zb-ctl config get_version host
...
You can now run any ot commands, refer to openthread manuals
You can now run any zb commands, refer to test-example-cli_nxp.txt

Remark:
By using zb-ctl to send a single command, the zb-ctl will close the connection to
zb_daemon after receiving the command response (Ok or error) BUT it will not display
the callback message from the stack to application.

Example:

$ zb-ctl zdo get_lqi 0x780B 0
command: zdo get_lqi 0x780B 0
get_lqi(0x780b) trans. seq num 5
Ok
$ (exited from zb-ctl)
=> We have lost the callback message:
" get_lqi_cb(0x780b, 5) Success, index 0, nb 1, total 1\n"
" 	 LQI[0]: dest 0x0000, lqa 9 (diag_data: lqi: 8, rssi: -78)"
In this case, it will be logged by zb_daemon_zczr:
[13:27:42.540] zb_daemon_zczr: lost: get_lqi_cb(0x780b, 5) Success, index 0, nb 1, total 1
[13:27:42.540] zb_daemon_zczr: lost: 	LQI[0]: dest 0x0000, lqa 9 (diag_data: lqi: 8, rssi: -78)
