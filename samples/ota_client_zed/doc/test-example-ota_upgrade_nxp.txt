Test Script - SDK Samples
===========================
 Objective:
   Test and test scripts under SDK Samples context, performs high-level/functionality checks.

 Devices:
   1. ZC - ota_server_zc
   2. ZR - ota_client_zr
   3. ZED - ota_client_zed

   Multi-Client functionality is possible, refer to readme-example-ota_upgrade_nxp.txt.

 Initial conditions:
   1. All devices are factory new and powered off until used.

 Test procedure:
   Item 1. Turn ZC on.
   Item 2. Turn ZR or ZED on.

 Expected outcome:
    For 'Test procedure' item 1:
      1.1. ZC -> Broadcast: Beacon Request
    For 'Test procedure' item 2:
      2.1. ZC -> Broadcast: Beacon
      2.2. ZR/ZED -> ZC: Association
      2.3. ZR/ZED -> ZC: BDB commissioning
      2.4. ZR/ZED -> ZC: Match Descriptor Request
      2.5. ZC -> ZR/ZED: Match Descriptor Response
      2.6. ZC -> Broadcast: Image Notify
      2.7. ZR/ZED -> ZC: Query Next Image Request
      2.8. ZC -> ZR/ZED: Query Next Image Response
      2.9. ZR/ZED -> ZC: Image Block Requests. ZC -> ZR/ZED: Image Block Responses
      2.10. ZR/ZED -> ZC: Upgrade End Request
      2.11. ZC -> ZR/ZED: Upgrade End Response
