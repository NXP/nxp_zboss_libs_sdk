Developing with ZBOSS for Zigbee
Memory configuration feature

The Zigbee application is characterized by the network size, traffic load, and other properties. By default, its configuration uses maximum values regardless of the device role.

You can modify two parts of the Zigbee stack memory usage to match the type of your application:

  • RAM usage – see Zigbee stack RAM usage configuration.
  • Persistent data size – see Zigbee stack flash usage configuration.
Note
The memory configuration must not be changed between firmware versions if the firmware is going to be upgraded using the OTA DFU.
